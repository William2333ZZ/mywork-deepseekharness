# 盯在用的 AI的规矩

口径、来源、格式、教训，一行一条（mywork_remember 追加；用户在资料栏里改和删）。

- {date} （来源）价格、下线日期以厂商官方页面为准；models.dev、OpenRouter、deprecations.info 只当线索，引用时标「第三方」。
- {date} （口径）月费变化按上月账单的用量算；没有账单就写「没有用量数据」，不估。
- {date} （格式）每个数字标出处：我们测的 / 账单 / 官方 / 厂商说。
- {date} （格式）短句，不用排比和套话。
- {date} （格式）清单里「名称」只写包名或模型名本身（openai，不写 openai（Node））；「环」是技术雷达的环：在用 / 试用 / 观察 / 暂停；「启用」写 是 / 否。
