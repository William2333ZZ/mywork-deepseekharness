DeepSeek 前阵子开源了 Harness（下面简称 dsh），定位是"编码智能体的工作台"：本地跑，有会话、工作区、终端、文件树，模型自己写代码、跑命令。我用了一段时间，发现它的插件机制其实很强：侧栏、设置页、工具、命令、HTTP 路由、甚至整个 UI 都能被插件替换，而且社区已经有一批不错的插件。

于是我做了一件事：一行 dsh 源码都不改，只用插件，把它改成我自己想要的工作台。 现在开源了，叫 MyWork Kit，仓库在文末。

这篇讲三件事：它能干什么、怎么做到的、踩了哪些坑。

一、它现在长什么样

新建对话页有四个起点，也是我给它定的四个用途：

1. 上网查资料：右边是一个真的 Chrome

右侧栏里是一个后台真实 Chrome 的实时画面。模型用 Playwright 打开网页时，你在旁边看着它翻页、点按钮；你也可以自己接管，点、滚、打字都直接转发过去。

地址栏我照着 Chrome 做的：输网址直接打开，输一句话就去搜索（Bing / Google / 百度 / DuckDuckGo 可选），历史和书签会弹建议，输 git 会自动补成 github.com，画面里按 Ctrl/Cmd+L 跳回地址栏。面板拖多宽，页面就按多宽排版，不留黑边。

典型用法：

打开这个网址给我看，并把页面要点整理成 5 条：https://……

模型开页面、你看画面、总结出现在对话里。全程没有 iframe，这是我给这套东西定的一条规矩。

2. 做表格和演示文稿

这块用的是 Univer 官方给 dsh 做的插件。你说：

根据下面的资料做一份演示文稿，5 页以内，每页一个要点，做完截图给我看：……

模型会新建 .univer 文件，在一个可拖动的实时窗口里边做边校验（版式检查、截图自查），完成后会话里留一张审阅卡片，能全屏看、能对比版本、能导出 .pptx。表格同理，最后导出 .xlsx 直接用 Excel / WPS 打开。

3. 定时任务与提醒

定时任务来自社区的 Automation 插件，按计划在独立会话里跑。我在它的任务弹窗里加了一栏「运行结束发到 IM」：每个任务自己选发到哪个聊天，每次结束发还是只失败时发。

创建一个定时任务：每天 09:00 检查 GitHub 上我关注的仓库有没有新 release，跑完把结果发到微信。

这句话说完，任务建好、通知也配好。提醒是另一套：/remind 10m 喝水、/remind daily 09:00 站会，到点页面弹窗、浏览器通知、提示音，可以顺带发到 IM。

4. 微信 / 飞书助理

社区的 dsh-im-connect 能把微信、飞书、钉钉、企业微信、QQ、Telegram 接到本机 dsh。在微信里对机器人说话，就是在和本机的一个会话对话；我补了"从桌面主动发消息"这条路：对模型说"把上面的结论整理成 3 句话，发到微信"，或者 /imsend 内容，或者页面上的发送卡片。

一个要提前说的坑：微信个人号机器人只能在你给它发过消息后的一段时间内回复，这是平台限制。要准点推送，通知目标选飞书 / 钉钉 / 企业微信更稳。

还有

  • MCP 连接器在应用内配置，粘贴一段 mcpServers JSON 就能导入，保存即挂载。
  • 三种风格（Claude Code / Codex / Swiss）× 浅色 / 深色，界面缩放 80–150%。其中 Swiss 风格是用一个设计系统生成器（ui-ux-pro-max）出的方案，我把它落成了主题。
  • 插件市场、Mermaid 图渲染。

二、怎么做到"不改 dsh 一行"

这部分给想自己折腾插件的人看。

组合包。 dsh 有 dsh.bundle + cordis.patch.yml 的机制：一个插件可以声明"我带着这些成员"，并且给宿主打 patch（比如禁用官方侧栏、插入自己的）。MyWork Kit 就是一个组合包，成员一部分是我写的，一部分是社区的 npm 包，设置页里能看状态、一键补装。

能力都走 dsh 的槽位。 侧栏、设置页标签、右侧栏的标签类型、输入框旁的按钮、系统提示词段落、工具、命令、HTTP 路由，全是 ctx.slots / ctx.tools / ctx.commands / ctx.webServer 这一套注册进去的。要接第三方插件（比如 Automation 的任务弹窗）又没有扩展点时，就用 DOM 注入 + MutationObserver，然后把数据存到自己的接口。

浏览器半身零构建。 dsh 的前端插件是一段 window.__ModuleLoader__.load({ id, factory })，react 由宿主提供。我写了个几十行的打包器，把纯 CommonJS 源码包一下就能用，不需要 webpack。

一份 dsh 核心。 这是最容易踩的坑：插件的 dependencies 里千万别写 @deepseek-ai/dsh-*，否则 profile 里会出现第二份核心模块，新建会话直接报 tools.restrict() requires a scoped context。

三、踩过的坑，挑几个

  • 官方的 Playwright provider 在 attach 模式下只给第一个会话用，其它会话报错。我自己给每个会话挂了一份非独占的 MCP，所有会话都能上网。
  • 界面缩放不能简单 zoom 整个页面：dsh 的浮层菜单用视口坐标定位，会整体偏 10%。改成只缩放应用根节点，再给 JS 定位的浮层做反向缩放，Univer 窗口保持 1:1，才全部对上鼠标。
  • 一个社区排版插件在新版 dsh 上把行距放大了一倍、还让字号设置失效，排查了半天以为是我的问题，最后把它移出了成员列表。
  • 微信推送的时效问题，上面说了。

每个坑在仓库的 Issues 里都有原因和验证记录，README 的「已知的坑」也有汇总。

四、怎么用

三种方式，按省事程度排：

  1. Windows 免安装包：Releases 里下载 Mywork-DSH_desktop-win-x64.zip，解压双击。自带 Node、dsh、Chrome 和装好的插件，不用配环境。未签名，第一次会过一下 SmartScreen。
  2. 一条命令试用（有 Node 24 就行，不碰你现有的 dsh）：git clone 后 bash scripts/dev-env.sh。
  3. 装进你自己的 dsh：bash scripts/install.sh web && dsh web。

API key 在设置里填一次就行，所有个人数据都在数据目录里，升级不丢。
