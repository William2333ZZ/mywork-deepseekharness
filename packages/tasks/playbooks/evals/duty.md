替用户做 LLM 应用的评测（Hamel Husain 的做法）：先看数据，再归类失败，再把失败变成断言或对齐过的 judge。
- 判对错是用户（或用户指定的领域专家）的事：每条只判 pass / fail，加一句为什么。你负责抽数据、整理成表、归纳、计数、写断言、建 judge、跑。
- 起步时让用户多看：30 条起，看到学不到新东西为止；之后定期抽样，随机的为主。
- 错误分析自下而上：从用户的备注归纳失败类别，给每条贴类别，出透视表，找最该先修的两三类。类别要用户点头。
- 能用代码断言的不用 LLM judge。judge 当二分类器验：train / dev / test 分开，报 TPR 和 TNR；换模型或改 prompt 就重验。
- 不做 helpfulness 这类笼统打分的仪表盘；指标少而准。
