# MyWork v2 · 整体流程

> 一句话：**你在一个地方和助理说话；它在后台干活；结果回到同一个地方。** 页面是为了这条流程服务的，不是反过来。

## 1. 正常的一天

| 时刻 | 人在做什么 | 助理在做什么 | 在哪里发生 |
|------|-----------|-------------|-----------|
| 早上打开 | 看一眼昨夜到现在发生了什么：简报到了没、昨天交办的做完没、有没有失败或要我拍板的 | 例行已经跑完，简报和变化摆在最上面；失败的标出来 | **今日**的清单 |
| 上午交办 | 顺口一句：「把昨天的会议纪要整理成待办」「查一下这三家的定价」「每周一早上给我汇总」 | 短问题当场答；要干活的接下去后台做，回一句「已交给后台，做完叫你」；带时间的安排成例行 | **今日**的对话框 |
| 干自己的活 | 不管它 | 跑任务、核验、通知 | 后台；飞书 / 通知 |
| 回来看 | 看结果，打分，追问「再短一点」「换成表格」 | 在同一个任务里接着改 | **任务页**（回答就是页面） |
| 下午随手 | 「刚才那份改成英文发我」「这个每天盯着，有变化告诉我」 | 追问接在原任务上；盯着的事变成例行 | 今日的对话框 / 任务页的回复框 |
| 手机上 | 看通知、读结果、点个「有用」、说一句 | 同上 | 同一套页面，单列 |
| 周五 | 「这周做了什么」 | 一份周报，来自这周的交付物 | 一条例行，或当场问 |

三条主线，都从同一个入口出发：

```
今日的对话框 ──┬── 短问题 ────────────▶ 就地回答（对话）
               ├── 要干活的 ──▶ 后台任务 ──▶ 通知 ──▶ 任务页（结果 · 追问 · 打分）
               └── 带时间的 ──▶ 例行 ──▶ 每次到点跑成任务，先说变化 ──▶ 今日清单
```

## 2. 四个对象，每个只在一处管理

| 对象 | 是什么 | 出现在 | 在哪里管 |
|------|--------|--------|---------|
| 对话 | 你和助理说过的话 | 今日线程（可回看昨天） | 就在那里 |
| 任务 | 助理在后台做的一件事，做完有结果 | 等你看栏 · 左栏一行 · 任务线程 | 任务线程（追问、再来一次、重新核验） |
| 例行 | 到点自动做的事和提醒 | 左栏一行 · 例行线程 | 例行线程的 ··· |
| 结果 | 任务交付的东西 | 任务线程的回复段 · 交付物查找页 | 任务线程（打分、··· 导出） |

## 3. 页面地图（2026-09-30 起，见 TEAMMATES.md §8）

- **左栏**：一列会话。搜索 · 「+」；「今日」固定第一行；其余任务与例行按最近活动混排，每行一句最近的话；底部 交付物 · 设置。
- **今日线程**：头部一行日期与状态词；吸顶的等你看栏（点开原地展开清单）；今天的线（你的话、回复、原地更新的交办行）；底部 dock。可「加载昨天」只读回看。
- **任务线程**：原话在上，回复段在下（结果行、正文、一行核验与评价），过程折起来，底部接着说。
- **例行线程**：每次运行一段，没变化只一行；··· 里跑一次、暂停、改要求、删除。
- **新线程**：「+」打开，一句「要什么结果？」，发送一定建任务。
- **这台电脑**：任务用到浏览器时，显示器键拉出右栏的画面；点画面接管。

## 4. 今日对话框的三条规则

1. 助理先判断：一句话能答的当场答；要查、要写、要生成文件的交给后台（建任务），回一句话说明；带时间的安排成例行。判断是它的事，不是用户的。
2. 后台建了任务，今日清单里立刻多一行「在跑」，做完变成「已交付」；对话里那句话可以点开进任务页。
3. 今天的对话是一条线，明天是新的一条；昨天的线在今日线程里往上翻能看到（只读），助理也记得跨天的最近几句，需要就问。

## 5. 通知的纪律

- 打扰的单位是**变化**：任务做完、例行有变化、提醒到点、失败。例行没变化不打扰。
- 「提醒我做 X」：X 是 MyWork 自己能做的（写周报、整理、汇总），就到点做好交给用户，而不是提醒用户去做；只有用户自己才能做的（喝水、开会、交周报）才是提醒。周报、日报从 MyWork 自己的工作记录里写：今日的提问和回答、交办的任务、交付物和核对结果。
- 一次变化只打扰一次：应用内一条，飞书一条（配置了才发）。
- 通知点开就是那个任务页。
