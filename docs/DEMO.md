# 交易工作台 · 演示讲稿

三分钟，五个动作，一句话主题：**看盘、提问、留档、复盘，用市场交易数据而不是新闻。**

录好的演示：[docs/demo/trading-workbench.gif](demo/trading-workbench.gif)（同目录有 mp4）。下面是现场演示的步骤和话术，按顺序做即可，每步不超过半分钟。

## 准备

- 开发环境：`env -u MYWORK_DESKTOP bash scripts/dev-env.sh start`，浏览器打开 web.log 里的带 token 地址。
- 提前做一次「分析」，让报告页里有一份真实报告；提前在巡检页选好飞书账号。
- 风格用默认的「市场终端」，浅色或深色都可以；1440 宽最好看。

## 1. 启动即驾驶舱（30 秒）

打开就是驾驶舱，不是聊天窗口。

- 指着市场温度：恐惧贪婪、实际利率、利差、黄金、铜金比、原油、汇率、BTC 基差、CFTC 持仓、A 股板块、两个 Polymarket 合约。每张卡一个状态词，下面一句话是规则算出来的市场状态。
- 往下：今日变化（和昨天快照比变动最大的信号）、板块资金流、我的标的（自选和持仓一张表，有持仓的行显示浮动盈亏）、报告档案。
- 说明：所有数据源免费无需 key，15 分钟刷一次；没有下单按钮，持仓是自己填的数量和成本。

话术：「它每天回答三个问题：市场在哪、我的仓怎么样、今天有什么不一样。」

## 2. 提问（30 秒）

点左栏「提问」。

- 输入框上方是驾驶舱要点：行情条、我的标的、今日变化、最近报告。
- 下面一行常见问法，点一条就填进输入框。
- 输入框占位是「问一个市场问题」。

话术：「提问的时候数据就在眼前，不用自己复述。」

## 3. 按「分析」（60 秒）

在「我的标的」里点黄金那行的「分析」。

- 工作台自动开一个新对话，把这只标的的报价、你的持仓、市场温度和该取哪些数据一起发出去，不用再按发送。
- 看模型调用 oracle_docs、oracle_fetch：它先读方法论，再并行取期权链、CFTC 持仓、国债曲线等至少三个独立维度。
- 会话标题就是问题，没有 emoji 和分类前缀。
- 报告出来是固定结构：分层信号表、矛盾分析、概率场景、信号一致性。写完自动存档。

话术：「它只用交易数据，不看新闻不看观点；结论一定带概率和时间窗口。」

## 4. 报告与复盘（30 秒）

点左栏「报告」。

- 每份报告一行：概率是主数字，标题、结论、标的与主题标签、日期。
- 同一标的的多次报告会连成一条概率历史，这就是复盘。
- 右侧「对 / 错」是事后验证，两周没标的报告巡检时会提醒。
- 回到驾驶舱，我的标的那一行现在带着「52% 09-27」，报告结论挂回持仓。

## 5. 巡检（30 秒）

点左栏「巡检」。

- 一个开关、一个时间、三个勾选、一个飞书账号。
- 点「预览内容」看今天的摘要；点「现在推送一次」，手机上的飞书立刻收到。
- 说明：这是纯数据摘要，不含建议；每天到点自动推。

话术：「盘前八点半，飞书里先有一份摘要；打开工作台第一屏就是变化。」

## 常见问题

- 数据来自哪里？Polymarket、Kalshi、美国国债、CFTC、SEC、Deribit、CoinGecko、BIS、世界银行、Yahoo、东方财富、CNN 恐惧贪婪、网页搜索，全部免费。
- 能下单吗？不能，也不会做。它是分析工作台。
- 换模型？设置里的模型选项是 dsh 自带的，任何 DeepSeek 模型都行。
- 风格？市场终端是默认，另有 Claude Code、柔和、极简、粗野四种，浅色深色都过 AA。
