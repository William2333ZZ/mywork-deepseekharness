# MyWork 的标

一个 M，最后一笔收成一个勾。M 是名字，勾是「事情做完」，对应 交付 和 核验。

- `mark.svg` — 24 格字形，描边 3.4（约容器的 1/7），圆头圆角。用 `currentColor`，放在深底上用米白，放在浅底上用暖黑。
- `icon.svg` / `icon-1024.png` / `icon-256.png` — 应用图标：暖黑 `#1f1d1a` 圆角方块（圆角 22%），字形占边长的 2/3。
- `icon.icns` — macOS 用，`apps/desktop/build.mjs` 打包时替换 Electron 自带的 `electron.icns`。

界面里的用法：侧栏品牌位（`MyworkSidebar.tsx` 的 `BrandMark`）22px 深底小方块；有任务在跑时这一笔自己画一遍（`stroke-dashoffset` 动画），不转圈。对话里回复旁不放头像，学 Grok。

## 规则

- 单色。深底米白，或浅底暖黑。不加第二种颜色，不加渐变、描边、阴影。
- 一种笔画粗细，两头都是圆头。
- 四周留 20% 到 25% 空白，16px 也要认得出。
- 动的时候只做「画一遍」或「呼吸」，不旋转、不弹跳。

## 它们是怎么做的（2026-09-30 看官网得到的）

**Grok**：一笔填充形，一道由粗到细的斜线甩出去时带起小半个圆环，像彗星划过轨道。黑底白形，App Store 上是金属质感的白。网页标志用 Lottie 播放。界面：接近纯黑的整页，中间一句「我们应该探索什么？」，底部深灰大圆角输入框，左下「+」，右下模型标签和圆形上箭头发送键。Companions（Rudi 小熊猫、Ani）是 App 里的 3D 陪伴角色，不进品牌和界面。

**Manus**：一只手。四段胖胖的圆头短笔画当手指，一团掌心，暖黑 `#34322D`，白底圆角约 16%。字体 Libre Baskerville + DM Sans。品牌页只有徽标、字形、图标，没有吉祥物。界面：白底衬线大标题「我能为你做什么？」，白色卡片输入框，下面一排功能胶囊。

**Cue（Manus 2.0 的个人 agent 应用，2026-09-28 发布）**：图标是一个灰色的八角印章形（圆角的两个方块叠成），上面一张脸：左眼是竖的长圆点，右眼是一个「<」。脸是单独一层 SVG，会眨。每个 agent 有自己的电话、邮箱、钱包、电脑；多个 agent 可以拉进一个群聊协作。它的可爱来自「印章形 + 两笔的脸」，而不是画一只动物。

MyWork 选了 Manus 那条路：字形管认得出，不做脸。要是以后想要一只有表情的小东西，按 `../../v2/FLOW.md` 的四个时刻（空页、等待、做完、出错）单独做，不进品牌位。
