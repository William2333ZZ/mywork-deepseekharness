# 每日论文的规矩

这份文件说清订什么、怎么过表、怎么写分流。哪里不顺手就改这里，用户和你一起改。

## 订阅

- 分类：（开张时写，arXiv 分类代号，例如 cs.CL, cs.LG）

## 我关注什么

（开张时写：在做什么、想追什么、什么不要。下面是兴趣画像：反复出现的主题、方法、作者。）

## 怎么过表（苏剑林的「刷」）

1. 先调 mywork_arxiv_today：程序取当天 arXiv 全表（新、交叉、更新），按 arXiv 的原序存成 每日/YYYY-MM-DD.json；新和交叉的标题清单在 每日/YYYY-MM-DD.标题.txt，更新的在 每日/YYYY-MM-DD.更新.txt。
2. 新和交叉的逐篇看标题，一篇不跳；标题拿不准的去 json 里读摘要。更新的只看 收藏.md 和知识库里出现过的。
3. 刷是筛，不是读：目的是挑出值得精读的，不代替精读。不凑数，没有就写没有。
4. 写 每日/YYYY-MM-DD.md，三节：
   - `## 必读`（最多 5 篇）每篇一小段：`[arXiv 号] 标题`，下面四行——做了什么 / 和你的关系 / 可借鉴什么 / 还值得追问什么（每项一句；信息不够就写「要读全文确认」）。
   - `## 值得看`（最多 15 篇）每篇一行：`[arXiv 号] 标题 —— 一句话为什么`。
   - `## 今天的面貌` 两三句：这一天这几个分类大家在做什么、有没有扎堆的方向。
   最后一行：`过了 N 篇（新 a · 交叉 b），必读 x，值得看 y。`
5. 论文一律写 arXiv 号（2610.02293 这样），用户和别的同事靠它找到论文（https://arxiv.org/abs/号）。
6. 回话只说必读的标题和一句话，别把整份贴出来。

## 兴趣

- 收藏.md：用户让你收进知识库的论文，你记一行「- 日期 [arXiv 号] 标题」，越往下越新；越新越说明现在的兴趣。
- 收进知识库：用 mywork_hand_to 交给知识库同事——先把摘要存成一个 md（开头写「来源：https://arxiv.org/abs/号」「PDF：https://arxiv.org/pdf/号」），作为 files 一起交，text 写「收进知识库：标题」。
- 文献库/：用户给的文献（Zotero 导出、论文清单），当兴趣参考，不用逐篇读。
- 用户说「这类以后别推」「这个方向多给我看」，记进「我关注什么」。
