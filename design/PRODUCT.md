# 交易工作台 · 产品设计

> 一个人的交易分析工作站。它不是聊天软件，也不是编程助手。它每天陪你做四件事：看盘、提问、留档、复盘。

## 1. 给谁用，什么时候用

个人投资者或独立交易员，同时看 A 股、美股 / 商品 / 外汇、加密。不写代码，不想学工具。一天里三个时刻打开它：

| 时刻 | 想要的 | 产品该做的 |
|------|--------|-----------|
| 盘前 8:30 | 隔夜发生了什么，我的持仓有没有事 | 巡检报告已经推到飞书；打开工作台第一屏就是变化 |
| 盘中 | 某只标的 / 某件事到底怎么看 | 一句话提问，带着当前数据，几十秒出结构化报告 |
| 盘后 | 今天的判断留下来，过段时间回头看对不对 | 报告自动存档，同一问题的概率能对比 |

## 2. 核心循环

```
看盘 ──▶ 提问 ──▶ 报告 ──▶ 留档 ──▶ 复盘
 ▲                                   │
 └───────────── 巡检（每天自动） ◀────┘
```

每一步都对应一个具体界面，没有多余的页面：

- 看盘 = 驾驶舱
- 提问 = 驾驶舱顶部的提问框（不是一个单独的「新对话」页）
- 报告 = 分析对话（dsh 的会话视图）
- 留档 = 报告页（模型写完自动存）
- 复盘 = 报告页里同一问题的历史
- 巡检 = 巡检页（一个开关加一个时间）

## 3. 信息架构

```
交易工作台
├─ 驾驶舱          首页。提问框 / 市场温度 / 我的标的 / 今日变化 / 最近报告
├─ 报告            所有报告，按标的和主题筛，同题对比
├─ 巡检            每日巡检的开关、时间、内容、推送渠道、执行记录
├─ 分析记录        左栏列表：过去的每一次提问（会话），标题就是问题
└─ 设置            数据源状态、涨跌配色、风格、通知账号、模型
```

去掉的东西，以及为什么：

| 去掉 | 原因 |
|------|------|
| 侧栏的「分析」和「新分析」两项 | 「分析」是 dsh 的「回到当前对话」按钮，「新分析」是开新对话，两者都是聊天软件的概念。交易员的动作是「提问」，提问框放在驾驶舱上，对话自然打开；回到某次对话从分析记录点。 |
| 「新对话」首页（口号 / 问题卡） | 它是一个空页面，让人先选题再输入。提问框在驾驶舱上，旁边就是数据，不需要过渡页。 |
| 驾驶舱的五个问题面板 | 它们是宏观问题的模板，占了半屏，却和用户的标的无关。模板降级成提问框下面的短语，真正的入口是「我的标的」里每一行的「分析」。 |
| 更多 / 消息通知 / MCP / 插件市场 | 通知渠道属于巡检页；其余是开发者能力，只留在设置里。 |

## 4. 各屏设计

### 4.1 驾驶舱

```
┌──────────────────────────────────────────────────────────────────────┐
│ 驾驶舱                                        更新于 3 分钟前  刷新 │
├──────────────────────────────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────────────────────────────┐ │
│ │ 问先知：黄金现在要不要加仓？                            [问先知] │ │
│ │ 会带上：市场温度 · 我的标的 · 持仓          模板 ▾              │ │
│ └──────────────────────────────────────────────────────────────────┘ │
│                                                                      │
│ 市场温度                                                             │
│ ┌────────┬────────┬────────┬────────┬────────┬────────┐              │
│ │恐惧贪婪│10Y实际 │10Y-2Y  │黄金    │铜/金   │BTC基差 │  … 一行，  │
│ │37 +7周 │2.83%   │36bp    │4,321   │1.566   │0.1%    │  横向可滚  │
│ └────────┴────────┴────────┴────────┴────────┴────────┘              │
│                                                                      │
│ 我的标的                                            + 添加标的       │
│ 标的        最新     日      30日   持仓        浮动盈亏    操作     │
│ 黄金        4,321   -0.54%  ▁▂▃▅   2 @ 4000    +642 +8.0%  分析     │
│ 贵州茅台    1,237   -1.14%  ▅▃▂▁   —           —           分析 资金流│
│ NVDA        225.07  +0.22%  ▂▃▅▆   —           —           分析     │
│ BTC         84,959  —       —      —           —           分析     │
│                                                                      │
│ 今日变化                                   最近报告                  │
│ · 恐惧贪婪 30 → 37，一周内最大升幅          · 黄金 6-12 月正收益 55% │
│ · 黄金基金净多头连续两周减仓                    2 天前 · 资产择时     │
│ · 汽车零部件板块主力净流入 9.9 亿            · 全部报告 →            │
└──────────────────────────────────────────────────────────────────────┘
```

要点：

- **提问框在最上面。** 输入一句话，按「问先知」，工作台开一个新对话，把当前的市场温度、自选、持仓一起交给模型，并且直接发送，不需要再按一次。框下面一行小字说明会带上什么，让人知道不用自己复述数据。
- **模板是短语，不是面板。** 「模板 ▾」里是十来条一句话的问题（评估某事件概率、判断某资产是否值得买、A 股主力在买还是卖…），点一条填进框里，光标停在要补的地方。
- **我的标的是驾驶舱的主体。** 自选和持仓合成一张表：有持仓的行显示数量、成本、盈亏，没有的显示破折号。每行一个「分析」按钮，问的是这只标的，模型拿到的是它的价格、资金流、期权、持仓等数据。A 股行多一个「资金流」。加标的是一行内联输入。
- **市场温度压成一行。** 十二张卡变成一条可横向滚动的小卡带，每张只留数字和变化。悬停看含义。
- **今日变化**是新的：和昨天快照相比变动最大的三到五条信号，用一句话写清。它回答「今天有什么不同」，这是盘前最想知道的。
- **最近报告**只放三条，指向报告页。

### 4.2 分析（对话）

保留 dsh 的会话视图，只改三处：

- 会话标题就是问题。
- 输入框占位是市场问题。
- 报告写完后，页面底部出现一张「已存档」卡：概率、窗口、一句结论，按钮「在报告页查看」。这是模型调用 `oracle_report_save` 的可见回执。

### 4.3 报告

```
┌──────────────────────────────────────────────────────────────────────┐
│ 报告                       筛选：全部标的 ▾  全部主题 ▾  搜索 ______ │
├──────────────────────────────────────────────────────────────────────┤
│ 55%   黄金 6-12 月正收益概率                     资产择时 · 9月27日  │
│       利率说卖、价格说买；实需吸收利率逆风，投机盘在撤…  打开对话 ▸ │
│       历史：9/20 48% → 9/27 55%                                       │
├──────────────────────────────────────────────────────────────────────┤
│ 4.5%  日本 2026 年衰退                              衰退周期 · 9月26日│
│       …                                                              │
└──────────────────────────────────────────────────────────────────────┘
```

- 每条报告一行：概率是主数字，标题、一句结论、主题标签、日期、打开对话。
- **同题历史**：同一标的或同一问题的多次报告，把概率按时间连起来显示，这是复盘。判断「同题」用报告的标的和主题字段，模型存档时填。
- 报告可以删除，可以标记「验证过：对 / 错」，供以后统计。

### 4.4 巡检

```
┌──────────────────────────────────────────────────────────────────────┐
│ 巡检                                                                 │
│                                                                      │
│ 每日巡检   [开]   时间 08:30                                          │
│ 内容       ☑ 市场温度变化  ☑ 我的标的与持仓  ☑ 报告需要复核的         │
│ 推送到     飞书 · 张三（已连接）  ▾            测试推送               │
│                                                                      │
│ 执行记录                                                             │
│ 9月27日 08:30  已推送  黄金 -2.6%，恐惧贪婪 37，两条信号变动  查看    │
│ 9月26日 08:30  已推送  …                                             │
└──────────────────────────────────────────────────────────────────────┘
```

- 一个开关、一个时间、三个勾选、一个渠道。背后是 dsh-automation 的定时任务加飞书直推，用户不需要知道这两个名字。
- 「测试推送」立刻跑一次。
- 通知渠道的配置（扫码、凭证）就在这一页里展开，不再是侧栏的「消息通知」。

### 4.5 分析记录（左栏）

- 列表标题就是问题，按时间倒序，不按工作区分组。
- 每条右侧显示时间，悬停显示概率（如果那次对话产生了报告）。
- 列表顶部一个「提问」按钮，等于回到驾驶舱的提问框。

### 4.6 设置

- 市场先知：数据源状态、自检、yfinance 安装、涨跌配色。
- 外观：风格与明暗（默认市场终端）。
- 通知账号：飞书 / 微信的连接状态（同巡检页）。
- 模型：dsh 自带。
- 其余开发者设置不出现在发行版。

## 5. 数据与节奏

- 快照每 15 分钟刷一次信号、5 分钟刷一次报价；保留最近 7 天的每日收盘快照，用来算「今日变化」。
- 所有数据源免费无 key；价格类经 Yahoo，需要 yfinance，缺失时对应行显示「未取到」而不是空白。
- 涨跌配色是用户设置，默认红涨绿跌；每个变动都带正负号。

## 6. 不做的事

- 不下单，不接券商或交易所账户，不显示「买入 / 卖出」按钮。持仓只是用户手填的数量和成本。
- 不做新闻流、不做社区、不做 K 线绘图工具。它回答问题，不替代行情软件。
- 不做「更多」菜单。功能不够重要就放设置，重要就放导航。

## 7. 分期

2. **报告页**：列表、筛选、同题历史、验证标记；对话底部的存档回执。
3. **巡检页**：开关、时间、内容、渠道、执行记录；今日变化（需要每日快照）。
